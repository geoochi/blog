# 我从哪里来

我说不上有什么可以称之为简历来介绍我自己的东西，我甚至不想回忆起我的历史。如果说汤饺的历史有个起点的话，那就是下面这段话

24年秋天，我抱着好奇心和兴趣帮朋友完成了一个室内机器人导航的定位模块，我觉得那个挺有意思的

于是一个早上就直接把思路搞清楚，然后动手写Python，然后实例贴二维码，然后跑机器狗，然后运行调试，就把实验给做出来了

差不多做到80%的时候，要研三开题了，但我觉得之后一年要做的事都没有什么意思，所以我直接把我写好的一堆Python脚本整理好，写好注释，交给我的朋友，然后直接退学

然后那时候，Cursor 刚刚起步，但我并没有完全进入Vibe Coding的状态，所以我还是选择继续玩我的前端、后端、manim、服务器、爬虫，各种GitHub Repo、这些开源的小工具、小玩意

到了25年，差不多整一年，从Cursor到Claude Code，AI的产能爆发了。但同时我也看到一大堆vibe出来的各种图文视频Coding垃圾充斥互联网

然后，我就对这个世界没有兴趣了

那一年我唯一做了几件事，就是玩了一会儿达芬奇的剪辑、waveform 编曲、Blender mmd的建模贴图动作渲染。还有 MiniQMT 的自动交易，其他时间基本都在望着天发呆

---

# 我要到哪里去

我并不知道我要最终要到哪里去，我说不上有一个什么称之为职业规划的东西，或者说人生目标的东西

我连下一个月的大模型的发展都预测不出来

那我为什么还要活着呢

可能是看到最近Omarchi发布了4.0版本，然后我看到DHH的眼睛中闪着光

我看到他从一年前对Cursor的平淡到现在对Agent的狂热

然后我就开始玩omarchy了，我又把我的codex装回来，下载了Workbuddy和Codebuddy，拼命的消耗着Token

职业是什么呢？工作是什么呢？我还是不知道，也不想知道

谁知道之后能做出什么东西呢？
